# Windows 검증 기록

검증일: 2026-10-19. 저장소에 게임·패치·도구 바이너리는 포함하지 않는다.

## 자동 검사

- 프런트엔드: TypeScript 타입 검사와 Vite 프로덕션 빌드 통과.
- Rust: `cargo fmt --check`, `cargo clippy --locked --all-targets -- -D warnings` 통과.
- `cargo test --locked --lib --bins`: 14개 통과. 별도 표시되는 ignored 3개는 부모 테스트가 실제 별도 프로세스로 실행하는 대기·자식 프로세스·표준입력 fixture다.
- 테스트 범위: SHA-256 일치·불일치·변경·취소, ZIP 경로 탈출 사전 차단, 패치 적용 순서, 소유 표시와 삭제 범위, 출력 충돌, Windows 파일 잠금, 서로 다른 드라이브의 복사·바이트 대조, 네 가지 파이프라인 조합, 비정상 종료·결과 누락·취소 시 후속 단계 중단, 일부 결과 저장 실패, DLC 인덱스·ID 보존, 코드 압축 플래그 보정, 실제 자식 프로세스 종료, Enter 입력 대기 처리.

## 실파일 연동

사용자가 `dev-temp/games/`에 제공한 본편 2,076,360,704바이트와 DLC 41,316,096바이트를 사용한다. 두 원본은 계획의 SHA-256과 일치한다. 실행 중 원본을 다시 검증하고, 작업 복사본도 동일한 SHA-256인지 검증한다.

| 입력 | 본편 형식 | 상태 |
| --- | --- | --- |
| 본편 | CIA | 생성·복사 대조·정리 통과 |
| 본편 | 3DS | 생성·복사 대조·정리 통과 |
| 본편+DLC | CIA | 두 결과 생성·콘텐츠 대조·출력 복사 검증 통과. 임시 폴더 정리 중 추가 검증 중단 |
| 본편+DLC | 3DS | 전체 실행 1회 성공. 두 결과 생성·출력 복사 대조·임시 폴더 정리 완료, 경고 없음 |

작업·출력 경로는 `dev-temp/integration/한글 work & (test)`와 `한글 output & (test)`로 한글·공백·괄호·`&`를 포함한다. 성공한 실행의 하위 폴더만 정리하며 실패 자료는 보존한다. 최종 결과 파일과 실패 로그는 이 Git 제외 폴더에서 확인할 수 있다.

DLC 단독 실파일 검증에서 33개 콘텐츠 재생성 후 원본 TMD의 타이틀·콘텐츠 인덱스·ID 일치를 확인했다. 본편 CIA·3DS 결과의 ExeFS를 직접 읽어 2차 패치의 코드와 바이트 단위로 일치하고 코드 압축 플래그가 해제되어 있음도 확인했다. 전체 조합 반복과 설치 재검증은 사용자의 지적에 따라 중단했다. 이후 사용자의 명시적 요청으로 미완료였던 본편 3DS+DLC 전체 흐름만 1회 실행해 성공했다. 설치·화면·다른 조합은 반복하지 않았다.

해당 실행 ID는 `1fc37b35-2871-49d9-8e48-6a4b19a1c484`이며, 실행 trace는 `dev-temp/integration/threeds-True-once.log`에 보존했다. 결과는 출력 폴더의 `SMT4F-KO-1fc37b35-2871-49d9-8e48-6a4b19a1c484.3ds`와 `SMT4F-KO-DLC-1fc37b35-2871-49d9-8e48-6a4b19a1c484.cia`다. 백엔드가 두 파일의 복사 대조 및 소유한 임시 폴더 정리를 완료하고 종료 코드 0, `warning: null`로 반환했다.

## 설치·화면

NSIS x64 설치 파일 생성 후 `dev-temp/installed`에 실제 설치하고 실행했다. WebView2에서 화면을 캡처하고 입력 9개, 초기 실행 비활성화, DLC 토글, 도구 경로 확인 명령, 잘못된 ZIP 경로의 한국어 오류 응답을 검증했다. 자동화 파일은 `scripts/gui-smoke.mjs`, 로컬 캡처는 `dev-temp/gui/screenshot.png`다. GUI 검증은 별도 디버깅 포트를 켠 검증 실행에서만 수행하며, 일반 앱은 디버깅 포트를 열지 않는다.

## 별도 환경에서 확인할 항목

- 개발 도구가 없는 별도 Windows PC에서 설치·전체 패치 실행. 현재 검증은 개발 PC의 Windows 환경에서 수행했다.
- 실제 기기·에뮬레이터에서 게임 진입, 저장, 본편·DLC 번역 표시와 플레이 동작.
- 실제 디스크 공간 소진, 권한 제한 계정, 전원 차단 같은 시스템 조건. 오류 분기와 파일 잠금은 자동 테스트로 확인했지만 시스템 조건 전체를 재현하지는 않았다.
- 네이티브 파일 선택 대화상자·클립보드·다운로드 링크의 직접 클릭과 실행 중 창 닫기 확인 UI에 대한 사용자 점검. 백엔드 프로세스 취소·종료는 자동 테스트를 통과했다.

파일 생성·구조 검증 성공을 게임 실행 검증 완료로 표시하지 않는다.
