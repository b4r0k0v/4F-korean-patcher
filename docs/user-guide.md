# 사용 안내

Windows 10/11 x64와 WebView2 Runtime이 필요합니다. 설치 파일을 실행한 뒤 앱을 여세요.

1. 아래 도구 ZIP을 직접 받아 해제하고, 실행 파일이 있는 폴더를 선택합니다. 다음 실행에도 도구 경로를 기억하고 다시 검사합니다.
   - [Batch CIA 3DS Decryptor](https://gbatemp.net/download/batch-cia-3ds-decryptor.35098/download?version=35152)
   - [포크 HackingToolkit3DS v9](https://github.com/b4r0k0v/HackingToolkit3DS/releases/download/v9/HackingToolkit3DSv9.zip)
2. 북미 UNDUB·DECRYPTED 본편 `.3ds`를 선택하고 SHA-256 일치를 기다립니다. 본편 1차·2차 패치 `.zip`을 순서대로 지정합니다.
3. DLC를 사용하면 UNDECRYPTED `.cia`와 DLC 패치 `.zip`을 함께 지정합니다.
4. 기존 작업 폴더와 출력 폴더를 선택하고 본편 CIA/3DS 형식을 고릅니다. DLC는 CIA로 생성합니다. 작업에는 원본 복사·추출·재생성이 모두 필요하므로 최소 15GB 이상 여유 공간을 권장합니다. 파일 구성에 따라 더 필요할 수 있습니다.
5. `패치하기`를 누릅니다. 원본을 다시 검증하고 전용 복사본에만 패치를 적용합니다. 처리 중 입력은 잠깁니다. 진행률을 제공하지 않는 도구는 단계 이름으로 안내합니다.
6. 완료 화면의 결과 경로를 확인하거나 `출력 폴더 열기`를 누릅니다. 기존 결과는 덮어쓰지 않습니다. 파일 생성 성공은 실제 기기·에뮬레이터에서의 게임 동작 확인과 별개입니다.

## 패치 ZIP 구조

1차는 ZIP 루트의 `ExeFS/`, `RomFS/`를 포함한 전체 내용을 적용합니다. 두 폴더는 각각 `ExtractedExeFS/`, `ExtractedRomFS/`에 병합합니다. 2차와 DLC는 ZIP 루트의 `patch/` 내부만 적용합니다. 상위 폴더로 감싼 ZIP, RAR, 7z는 지원하지 않습니다.

준비된 DLC ZIP의 `rebuild/content.0000.cfa`와 `rebuild/dlc.rsf`는 별도의 보조 빌드 입력으로 사용합니다. 두 파일은 함께 있어야 합니다. ZIP의 스크립트는 실행하지 않습니다. DLC 콘텐츠 인덱스·ID는 원본 TMD와 대조합니다.

## 취소·오류

`취소`를 누르면 새 단계 진입을 멈추고 도구와 자식 프로세스 종료를 기다립니다. 실행 중 창을 닫으면 취소·종료 여부를 확인합니다. 종료가 완료될 때까지 기다리세요.

실패·취소 시 작업 폴더는 보존됩니다. 화면의 `상세 오류 복사`로 실행 ID, 실패 단계, 원인, 작업 폴더, 저장된 결과 목록을 복사해 전달할 수 있습니다. 작업 폴더의 `error.json`과 `logs/`에는 호출 인자·표준출력·표준오류·종료 코드가 있습니다. 오류 자료에 로컬 경로가 포함될 수 있으니 공유할 내용을 확인하세요. 일부 결과만 저장됐다면 목록에 있는 파일만 저장 완료 상태입니다. `.partial` 파일은 최종 결과가 아닙니다.

- 원본 해시 불일치: 지정된 버전의 원본인지 확인하세요. 패치·도구에는 해시 검사를 하지 않습니다.
- 도구 파일 누락: 다운로드한 ZIP을 완전히 해제하고 실행 파일이 있는 폴더를 선택하세요.
- 도구 오류: 보존 폴더의 로그를 확인하세요. 다른 프로그램의 파일 잠금, 경로 권한, 여유 공간을 확인한 뒤 새로 실행하세요.
- 정리만 실패: 생성된 결과는 사용할 수 있습니다. 화면에 표시된 남은 임시 하위 폴더를 확인한 뒤 직접 정리하세요. 원본이나 상위 작업 폴더를 지우지 마세요.

자동 재개와 자동 도구 다운로드는 지원하지 않습니다.
