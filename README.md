# 진여신전생 4F 한글 패처

진여신전생 IV FINAL(4F)의 게임 파일에 한글 패치를 적용하는 Windows용 프로그램입니다. 화면에서 파일과 폴더를 선택한 뒤 **패치하기**를 누르면 됩니다.

화면 위쪽의 **1. 도구 준비 → 2. 파일 선택 → 3. 결과 설정** 순서로 진행하세요. 각 단계에서 선택한 내용은 다른 탭으로 이동해도 유지됩니다. **패치하기** 버튼과 진행 상황은 화면 아래에 표시됩니다.

원본 게임 파일은 그대로 두고, 한글 패치가 적용된 새 파일을 만듭니다. 게임 파일과 한글 패치 파일은 별도로 준비해야 합니다.

**1. 시작하기 전에 준비하세요**

- Windows 10 또는 11을 사용하는 64비트 PC
- 아래 표의 게임 원본과 한글 패치 ZIP 파일
- 여유 공간이 충분한 드라이브: 작업용으로 **최소 15GB 이상** 확보하세요. 결과 파일을 저장할 공간도 필요합니다.

~~설치 파일을 실행하고 안내에 따라 설치한 뒤,~~ **4F Korean Patcher**를 여세요. WebView2 설치 안내가 나오면 함께 설치하세요. 명령어를 입력하거나 개발 도구를 설치할 필요는 없습니다.

한글 패치 파일은 **[본편 1차 패치 배포글](https://gall.dcinside.com/mgallery/board/view/?id=megaten&no=47112)**과 **[본편 2차·DLC 패치 배포 페이지](https://github.com/snm01234/3DS-SMT4FINAL-KOR)**에서 준비하세요. 아래 표의 파일명 예시를 참고해 본편 1차·2차와 DLC 패치 ZIP을 구분해 주세요.

| 준비할 파일 | 설명 |
| --- | --- |
| 본편 원본 | 북미판·UNDUB·DECRYPTED 버전의 `.3ds` 파일. UNDUB는 음성이 일본어로 변경된 버전, DECRYPTED는 해독된 상태를 뜻합니다. |
| 본편 1차 패치 | 1차 한글 패치 `.zip`. 준비된 파일의 예: `SMT4Final 2.0.zip` |
| 본편 2차 패치 | 2차 한글 패치 `.zip`. 준비된 파일의 예: `SMT4F_KO_FOR_REPACK_v1.1.2.zip` |
| DLC 원본 — DLC를 사용할 때만 | 해독하지 않은 UNDECRYPTED 상태의 `.cia` 파일 |
| DLC 패치 — DLC를 사용할 때만 | DLC 한글 패치 `.zip`. 준비된 파일의 예: `SMT4F_KO_DLC_Patch_v1.1.2.zip` |

**본편과 DLC는 지정된 원본만 사용할 수 있습니다.** 이름만 바꾼다고 지원되는 원본이 되지는 않습니다. 올바른 파일인지 프로그램이 자동으로 검사하므로 해시값을 직접 계산할 필요는 없습니다.

지원하는 원본을 구분할 수 있도록 **SHA-256 해시값**을 아래에 적어 두었습니다. 파일명이 달라도 해시값이 같으면 같은 내용의 파일입니다. 아래 값은 패치를 적용하기 전 원본 기준입니다.

본편 원본 — 북미판·UNDUB·DECRYPTED `.3ds`:

```text
5FDBC59C52BC2747488C21502E0BBCD67910A557640ADEEF878C19328EF20168
```

DLC 원본 — UNDECRYPTED `.cia`:

```text
A18A1C190301F204602395B415BF37B2B4BDCD5C05709BBCD46EF7316936DB93
```

**2. 외부 도구 두 개를 준비하세요**

패처가 게임 파일을 풀고 다시 만드는 데 필요한 도구입니다. **DLC를 사용하지 않아도 두 도구 폴더를 모두 지정하세요.**

| 도구 | 다운로드 |
| --- | --- |
| HackingToolkit3DS | [이 패처용 포크 버전 받기](https://github.com/b4r0k0v/HackingToolkit3DS/releases/download/v9/HackingToolkit3DSv9.zip) |
| Batch CIA 3DS Decryptor | [Decryptor 받기](https://gbatemp.net/download/batch-cia-3ds-decryptor.35098/download?version=35152) |

각각 다운로드한 ZIP 파일을 마우스 오른쪽 버튼으로 누르고 **모두 압축 풀기**를 선택하세요. 압축을 푼 폴더는 패치가 끝날 때까지 그대로 두세요.

패처의 **외부 도구 준비**에서 `찾아보기`를 눌러 다음 폴더를 선택합니다.

- **HackingToolkit3DS 폴더:** 안에 `3dstool.exe`가 보이는 폴더
- **Decryptor 폴더:** 안에 `decrypt.exe`, `ctrtool.exe`, `makerom.exe`가 보이는 폴더

폴더를 열었는데 같은 이름의 폴더가 한 번 더 있다면, 안쪽 폴더까지 들어가 실행 파일이 보이는 위치를 선택하세요. 도구를 직접 실행할 필요는 없습니다. 선택한 도구 폴더는 다음 실행에도 기억합니다.

**도구 ZIP은 압축을 풀지만, 한글 패치 ZIP은 풀지 않고 그대로 선택합니다.**

**3. 게임과 패치 파일을 선택하세요**

프로그램의 **원본과 패치 선택**에서 아래 순서대로 `찾아보기`를 누르세요.

1. **본편 원본**에 준비한 `.3ds` 파일을 선택합니다.
2. 파일 아래에 **SHA-256 일치**가 표시될 때까지 기다립니다. 이는 지원되는 원본인지 확인됐다는 뜻입니다. 파일이 크므로 시간이 걸릴 수 있습니다.
3. **본편 1차 패치**에 1차 패치 ZIP을 선택합니다.
4. **본편 2차 패치**에 2차 패치 ZIP을 선택합니다. 1차와 2차 파일이 서로 바뀌지 않았는지 확인하세요.

DLC도 패치하려면 **DLC도 패치하기**를 체크하고, **DLC 원본**과 **DLC 패치**를 모두 선택하세요. DLC 원본도 검사 완료를 기다려야 합니다. 본편만 필요하면 체크하지 않고 넘어가세요.

**4. 작업 폴더와 결과를 저장할 폴더를 정하세요**

파일 탐색기에서 빈 폴더 두 개를 미리 만들어 두면 편합니다. 원하는 위치에서 마우스 오른쪽 버튼 → **새로 만들기 → 폴더**를 선택하세요.

| 화면 항목 | 어떤 폴더를 선택하나요? | 폴더 이름 예시 |
| --- | --- | --- |
| 작업 폴더 | 패치하는 동안 임시 파일을 만들 공간입니다. 여유 공간이 충분한 드라이브에 만드세요. | `4F 작업` |
| 출력 폴더 | 완성된 게임 파일을 받을 곳입니다. 찾기 쉬운 위치에 만드세요. | `4F 한글패치 결과` |

두 폴더를 선택한 다음 **본편 형식**을 정하세요.

- **CIA:** CIA 설치를 지원하도록 준비된 3DS에서 사용할 때 선택합니다.
- **3DS:** `.3ds` 파일 실행을 지원하는 에뮬레이터에서 사용할 때 선택합니다.

DLC 결과는 본편 형식과 관계없이 **CIA 파일**로 만들어집니다.

**5. 패치하기를 누르고 완료를 기다리세요**

모든 준비가 끝나면 **패치하기** 버튼을 누를 수 있습니다. 버튼이 흐리게 보이면 아직 선택하지 않은 항목이나 파일 아래의 검사 안내를 확인하세요.

실행 중에는 현재 작업 단계가 표시됩니다. 큰 파일을 처리하는 단계는 같은 문구가 한동안 표시될 수 있습니다. 완료 안내가 나올 때까지 프로그램을 켜 두세요. 중단해야 한다면 **취소**를 누르고 종료 처리가 끝날 때까지 기다리세요.

완료되면 **출력 폴더 열기**를 누르세요.

- 본편 결과: `SMT4F-KO-긴번호.3ds` 또는 `SMT4F-KO-긴번호.cia`
- DLC를 선택한 경우 추가 결과: `SMT4F-KO-DLC-긴번호.cia`

실제로는 `긴번호` 자리에 실행마다 다른 영문·숫자가 붙습니다. 기존 결과와 이름이 겹치지 않도록 하기 위한 것이며, 파일 이름을 직접 입력할 필요는 없습니다. 본편과 DLC는 **각각 별도 파일**로 만들어집니다.

작업이 성공하면 프로그램이 해당 실행의 임시 파일을 정리합니다. 완성된 파일은 출력 폴더에 남습니다. 파일 생성 완료 후에는 사용하는 기기나 에뮬레이터에서 직접 실행해 확인하세요.

**잘 안 될 때는 이렇게 해보세요**

| 상황 | 해결 방법 |
| --- | --- |
| 원본 SHA-256이 다르다고 나와요. | 준비한 원본의 버전이나 해독 상태가 다릅니다. 본편은 북미·UNDUB·DECRYPTED, DLC는 UNDECRYPTED 파일인지 확인하세요. 파일 이름을 바꾸는 것으로 해결되지 않습니다. |
| 외부 도구 파일이 없다고 나와요. | 도구 ZIP의 압축을 먼저 푸세요. 압축을 푼 폴더 안에서 위에 안내한 `.exe` 파일이 있는 폴더를 선택하세요. |
| 패치 ZIP의 필수 폴더가 없다고 나와요. | 1차·2차·DLC 패치가 올바른 칸에 들어갔는지 확인하세요. 배포받은 ZIP을 직접 풀거나 다시 압축하지 말고 그대로 선택하세요. RAR·7z 파일은 지원하지 않습니다. |
| DLC를 선택했는데 시작할 수 없어요. | DLC 원본과 DLC 패치가 모두 필요합니다. 본편만 하려면 `DLC도 패치하기` 체크를 해제하세요. |
| 파일 처리나 외부 도구 실행에 실패했어요. | 작업·출력 드라이브의 여유 공간을 확인하고, 해당 파일을 사용 중인 다른 프로그램을 닫으세요. 계속 실패하면 아래 방법으로 오류 내용을 전달하세요. |
| 결과는 만들어졌는데 정리에 실패했다고 나와요. | 출력 폴더의 결과 파일은 생성된 상태입니다. 임시 파일이 남은 위치는 화면 안내를 확인하세요. |

해결되지 않으면 **상세 오류 복사**를 누르고, 문의하는 곳에 붙여 넣어 전달하세요. 어느 단계에서 문제가 생겼는지 확인할 수 있습니다. 실패·취소 시에는 원인 확인을 위해 작업 파일을 남겨 두므로, 문의하기 전에는 화면에 표시된 작업 폴더를 지우지 마세요.

더 자세한 내용은 [사용 안내](docs/user-guide.md), 확인된 테스트 범위는 [검증 기록](docs/verification.md)에서 볼 수 있습니다.
